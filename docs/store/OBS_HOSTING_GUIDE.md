# 隐私政策托管指南（华为云 OBS 静态站点）

> 目标：拿到一个**国内可稳定访问、支持 HTTPS** 的公开 URL，填进 AGC 的隐私政策栏。
> 文件：`docs/store/site/index.html`（4 KB，单文件，无外部依赖）

---

## 为什么不用 GitHub Pages

`*.github.io` 在中国大陆访问**经常不稳定甚至打不开**。AGC 的审核员在国内，审核时会**实际点开**这个链接。
打不开 = 直接驳回，白等 1–3 个工作日。所以选国内可访问的托管。

华为云 OBS 的优点：
- 国内各运营商访问稳定
- **标准域名支持 HTTPS**：`https://<桶名>.obs.<区域>.myhuaweicloud.com/index.html`
- 4 KB 单文件，费用基本为零

---

## 前置条件

- 华为云账号（可用你的华为账号直接登录 <https://www.huaweicloud.com/>）
- **完成华为云实名认证** —— 这是华为云独立的要求，与你已完成的**开发者实名认证是两回事**。没做的话会在建桶前卡住。

## 步骤

### 1. 进入 OBS 控制台
登录华为云 → 右上「控制台」→ 顶部搜索框搜 **对象存储服务 OBS** → 进入。

### 2. 创建桶（关键在权限）

| 字段 | 填什么 |
|---|---|
| 桶名称 | 全局唯一，只能用**小写字母、数字、中划线**，3–63 位。建议 `datelog-privacy`（被占用就加后缀，如 `datelog-privacy-2026`） |
| 区域 | 选国内区域，建议 **华北-北京四（cn-north-4）** |
| 存储类别 | 标准存储 |
| **桶策略 / 访问权限** | **公共读** ← ⚠️ 最关键。默认是「私有」，不改的话访问返回 **403 AccessDenied**，审核必驳 |
| 其他 | 保持默认 |

> 记下你填的**桶名称**和**区域**，URL 由这两个拼出来。

### 3. 上传文件
1. 进入刚创建的桶 → 左侧「**对象**」→「**上传对象**」
2. 选择桌面 `DateLog-隐私政策站点\` 里的 **`index.html`**
   > ⚠️ 上传后对象名必须就是 `index.html`（不要带中文前缀或改名），否则 URL 会很长且可能编码出错
3. 上传完成后，在对象列表里点该文件 → 「**复制链接**」（或「链接」），可直接拿到访问地址

### 4. 拼出访问 URL

格式（两种域名都可用，**推荐第一种，支持 HTTPS**）：

```
https://<桶名>.obs.<区域>.myhuaweicloud.com/index.html
```

以 `datelog-privacy` + 华北-北京四 为例：

```
https://datelog-privacy.obs.cn-north-4.myhuaweicloud.com/index.html
```

### 5. 验证（**必做**）

- 用浏览器打开该 URL，应看到粉白配色的「DateLog 隐私政策」页面
- **再用手机 4G/5G（关掉 WiFi）打开一次** —— 模拟审核员从公网访问
- 要看到正常页面，**不能**出现 `403 AccessDenied` 或 `404`

### 6. 填进 AGC

AGC → 应用上架 → **应用信息** → 「隐私政策」栏 → 粘贴第 4 步的 URL → 保存。

---

## 常见坑

| 现象 | 原因 / 解决 |
|---|---|
| `403 AccessDenied` | 桶策略不是**公共读**。桶 → 「权限管理」→「桶策略」→ 改为公共读 |
| `404 Not Found` | 对象名不是 `index.html`，或 URL 里桶名/区域拼错 |
| 打开变成**下载**文件而不是显示页面 | 对象的 `Content-Type` 不是 `text/html`。重新上传时在「更多」里指定 `text/html` |
| 建桶时按钮灰着 | 华为云未实名认证 |

---

## 可选：换成更短的 URL（不推荐折腾）

启用「**静态网站托管**」（桶 → 静态网站托管 → 启用，默认首页 `index.html`）后，访问地址会变成：

```
http://<桶名>.obs-website.<区域>.myhuaweicloud.com/
```

**但它只支持 HTTP**。要 HTTPS + 短域名得再绑定自定义域名 + CDN + 证书，成本和复杂度都上去了。
**直接用第 4 步的 HTTPS 对象地址就够了**，AGC 接受带 `index.html` 的完整 URL。

## 后续如果要改隐私政策内容

1. 改 `docs/store/PRIVACY_POLICY.md` / `privacy-policy.html`
2. 重新生成 `docs/store/site/index.html`（内容与 `privacy-policy.html` 保持一致）
3. 到 OBS 桶里**覆盖上传** `index.html`（URL 不变，无需改 AGC）
